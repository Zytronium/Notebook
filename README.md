# Mobile Notes App
An app for taking notes on your phone - a practice React Native app.  

I haven't used React Native in a while, I need a refresher on how it works. This is a good practice app that shouldn't 
take too long to make. At most a couple days for MVP. At best, a couple hours, assuming uninterrupted focus 
(which almost never happens). I will be keeping a log of the development process in [DEV_BLOG.md](DEV_BLOG.md).

## Features

- Persistent on-device storage for storing notes
- Notes list view
- Note viewer
- Note editor

## Stretch goals

- Markdown/formatting support
- Color support
- Export as PDF

## Learning goals

- React Native basics
- On-device persistent storage
- Coding without AI assistance (use the internet instead of AI for once! Break the addiction! Don't even use AI for ideas or debugging assistence unless you hours debugging a single bug)

## Tech Stack

- React Native
- Expo Go
